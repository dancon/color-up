# 当前设计要求与来源

产品为5–12岁儿童使用的Android平板涂色游戏，品牌「涂个彩 · Color Up!」、Logo与啵啵由用户授权使用。当前内容为36张新版插画／357个可涂区，单图5–17区，108支蜡笔。

用户提供的原型来源为 `/Users/bytedance/Documents/deepseek-harness/default-workspace/涂个彩` 中的交互稿、品牌文档与设计图。该路径仅记录来源，工程和skill不依赖此机器路径。原型v0.4在重绘前后未变化；36图重绘、每图最多20个大区，以及随后删除旧素材，是用户另外明确的要求。

采用的界面与交互要求：

- Q萌风格、奶油首页／画册、淡紫涂色场景、原品牌与吉祥物。
- 画册按系列筛选，并可组合轻松涂／接着画／我的作品；首页最多4张推荐，数量从内容清单读取。
- 方形画板；顶部返回、橡皮、撤销、重来、保存、声音与标题进度紧凑居中，距画框14dp，不遮挡画板。
- 108支蜡笔分18页，每页6支，箭头循环、18个页位点，无颜色轮或数字页码。
- 单笔锁定闭合区域，越界裁剪；橡皮同样限制，保留蜡笔纹理、炫彩渐变／闪粉与PNG导出。
- 固定4%笔宽，真实覆盖率55%阈值、首度完成庆祝、撤销与本机保存；庆祝不按用色数区分作品优劣。重来先确认，帮助与家长入口全页可达。
- 支持平板横竖屏旋转与窄窗口；方形画板及工具按实际宽高适配，控件至少48dp。旋转保留当前创作与选择。

用户在v0.6提交后授权从儿童产品与设计视角改进，并明确补充横竖屏旋转适配；本轮调整及理由见[产品与交互审视](product-review.md)。

旧SVG、旧图库生成代码、旧版入口、过期原型截图及失败候选已从当前仓库清理。原始原型目录没有修改；当前效果以[实机截图](screenshots/gallery.png)、[36图总览](../artwork/v2/overview.png)及[活动清单](../artwork/catalog.json)为准。

新增主题采用[线稿技能](../.agents/skills/create-coloring-artwork/SKILL.md)，生成原PNG后检验真实区域与人工分区预览，不能用程序图形替代原画或静默改写已有图稿身份。
