# v0.7 儿童游戏产品与交互审视

基线为提交 `3dd41d7`（v0.6.0）。本轮根据当前代码、四张实际界面截图及产品／交互两次独立审视作出改进；没有进行真实儿童访谈或可用性测试，以下是待真实使用检验的设计判断。

5–12岁跨度较大。本轮让低龄孩子更容易理解操作，也让较大孩子保留自主配色和选择画稿的空间；不按年龄锁内容，不增加账号、联网、付费、限时任务或连续签到。

| 观察到的问题 | 本轮落实的改进 | 验收重点 |
| --- | --- | --- |
| 绿色勾实际打开PNG文件选择器，容易与完成／日常保存混淆 | 存图改下载箭头，提高图标对比度；保留用途描述，在问号帮助中区分自动保存与另存图片。画板按钮按用户要求只用图标 | 图标清楚、触控至少48dp、用途描述可读；取消导出不改变作品 |
| 垃圾桶一击清空，恢复依赖孩子认识撤销图标 | 重来前展示当前画作→空白线稿的确认，提供继续画；确认后仍能一步撤销 | 取消无变化、只清当前图、撤销恢复 |
| 初次说明9秒消失，无效起笔也会隐藏；没有解释跨区域需要抬手 | 纸外有足够空间时指引保留到首条有效笔迹；其他窗口通过问号查看操作，底部始终显示当前颜色；火花仅反馈已接受笔画 | 无效起笔不触发成功反馈；色彩展示不被说明覆盖；锁区不变 |
| 灰星／少星只取决于颜色数量，有限配色也被呈现为低分 | 完成时统一为创作喝彩，允许继续画、另存图片或换图；不把用色多寡展示为作品优劣 | 单色与多色得到同等积极呈现；完成阈值、历史和内部统计保持兼容 |
| 只有主题筛选，多个半成品不易找回 | 增加轻松涂、接着画、我的作品，与主题取交集；空集合可以一键恢复全部 | 真实数量、多个半成品、清空后的完成历史、空状态恢复 |
| 竖屏只有横放提示，局部布局依赖横屏宽度 | 根据当前窗口宽高布局画板、工具与蜡笔；窄窗工具分行，首页按钮自适应；旋转保留创作与选择状态 | 横竖屏方形画板、无覆盖或截断、连续旋转与存档一致 |

绘画页不显示顶部品牌文字，工具保持纯图标；当前颜色的圆点、渐变与名称始终留在蜡笔上方，包括橡皮模式。橡皮状态由工具的选中边框表达。操作解释由问号帮助承担，不用文字标签或底部说明挤占创作界面。竖屏工具左右组贴齐两侧、标题独立居中；横屏保持画板上方的紧凑工具组。首页去掉四个规格胶囊，啵啵仅用轻起伏、摆动和呼吸感增强亲和力，系统关闭动画时静止；画册返回使用大箭头。

“轻松涂”按实际闭合区域不超过10个筛选，是本产品的便捷入口，不是年龄或儿童发展能力评级。所有36张画稿仍可自由选择，单图最多20区；108支蜡笔、蜡笔质感、锁区自由涂画与橡皮规则保持。

设计依据：[Google儿童应用指南](https://developers.google.com/building-for-kids/designing-engaging-apps)强调适配不同能力、简单一致的操作和明确反馈；[Android无障碍指南](https://developer.android.com/guide/topics/ui/accessibility/apps)给出小字至少4.5:1对比度及至少48dp触控目标的建议。具体到本游戏的筛选和庆祝调整属于本轮设计判断，不把指南当作效果已被证实的结论。

实际构建、设备、旋转与存档验证见[验证记录](verification.md)。后续真实儿童测试应覆盖5–6岁、7–9岁、10–12岁，观察能否独立开始、理解抬手换区、找回半成品及辨认重来／存图；不以成人代操作替代观察。
