# 儿童涂色插画制作

把用户给的主题做成能直接用于儿童涂色的原创插画。默认5–12岁、正方形、全图最多20个实质可涂闭合区域（含背景），10–16个宽大色块为目标，更简单也可以；用户本次年龄、题材、数量、尺寸和区域上限优先。保留主题的趣味动作与自然造型，别用程序拼几何部件代替插画。

## 选择交付范围

- 用户只要素材，或当前没有适配项目：读[素材制作](references/asset-workflow.md)，交付原PNG、完整提示词、真实QA和锁区几何。
- 当前在Color Up项目且未限定只要素材，或用户要求接入该项目：再读[项目接入](references/color-up-adapter.md)，更新清单并运行项目导入与检查，完成实际接入。
- 其他现有项目需要实现时，沿用其已有架构与导入接口；先完成通用素材包，再适配其接口。不要为了展示图片另建网站、演示App或无关流程。

## 执行要点

1. 从主题补足一个清楚有趣的动作，保持精简背景、流畅有机线条、白底黑线和宽大留白。批量使用统一brief，各图单独生成。`scripts/prepare.py`建立可携带候选包和提示词草案，不调用模型、不生成占位画。
2. 使用内置 `image_gen`，每张单独调用。无参考的新图不传引用参数；定向编辑先查看原图，再提供确切的本机图像路径。复杂图或机械细圈不合格时，保留好构图，只编辑多余线条；不要无限从头重生。无需依赖另一份imagegen技能或API密钥。
3. 将选定工具产物复制到候选包，保留原生成文件；用 `record_artifact.py`记录实际哈希及提示词。运行随技能携带的 `analyze_illustration.py`，按真实源尺寸提取全部色区、洞和1000坐标锁区数据。不能截前20区，也不能为了通过失败图悄悄改门槛。
4. 必须查看原PNG和编号掩码：主体不能与背景漏通，不能有难涂窄环／小夹缝；计数通过不证明艺术质量或闭合语义。失败只用内置图像工具修图，再记录、重测、复核。通过后才记录真实视觉检查；这不是另向用户索要批准。
5. 图像与几何冻结为同一个新ID。默认ID带随机版本后缀，不复用退役ID；不能将孩子原有笔迹映射到新几何。项目接入走 `add_to_catalog.py`及项目hook，素材本身不依赖Color Up。

原PNG是可见艺术，提取的多边形只负责裁剪／命中，不重画轮廓。实现时在笔迹上以Multiply显示白底黑线PNG（或保留原图并另导出墨线alpha），避免白底盖住涂色；缩略图降采样，限制全尺寸缓存。仅在用户要求交互实现时处理这些消费端细节。

脚本均在本技能 `scripts/`，位置以当前技能目录为准。依赖锁也随目录携带，不依赖原仓库绝对路径。完成时给出最终素材路径、实际区域数、使用的提示词记录、内置工具来源及项目验证结果；未做的设备／实现验收明确说明。
